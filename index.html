Ren'Py Console + Taboo Mode Guide

A player-friendly guide for adding one helper file, enabling the console, exposing the Settings > Gameplay > Taboo Mode menu toggle, and changing visible variables safely.

Single public HTML page Dark / light / system theme Clear file-vs-console examples Official Ren'Py references

1. Quick start

Goal: add one helper file, restart, use Shift + O only when console access is needed, then use the new Settings > Gameplay > Taboo Mode toggle.

Fastest option: you do not need to manually write the helper code. Download the already prepared console_taboo_unlock.rpy, save it directly into the game's game directory, and restart the game.
  1. Download console_taboo_unlock.rpy.
  2. Save it in the game's game folder, next to files like code.rpa and images.rpa. This is the same folder Ren'Py scans for auto-loaded .rpy files.
  3. Restart the game completely.
  4. Open Settings > Gameplay and check for Taboo Mode.
  5. Open the console with Shift + O only when you need to change variables manually.
Manual option: if you prefer creating the file yourself, use the copyable Auto-loaded file example in section 4. Do not paste that full helper-file block into the console window.

2. New menu function: Taboo Mode toggle

The helper file enables the game/patch flag that makes the Taboo Mode option visible under Settings > Gameplay.

Use the Settings menu item on the left, then the Taboo Mode radio buttons in the Gameplay tab.

3. File code vs console commands

Auto-loaded helper file

Put this type of code inside console_taboo_unlock.rpy. Ren'Py reads it during startup.

  • Good for enabling the console.
  • Good for exposing the Taboo Mode menu toggle.
  • Requires a full game restart after changes.

Console window

Type this type of code after opening the in-game console with Shift + O.

  • Good for money, choices, flags, and testing values.
  • Works while the game is running.
  • Some changes may need a save/reload or scene change.
Do not mix them: init python: and default lines belong in a .rpy file. Simple assignments like SMPlayer_Money = 999999 belong in the console window.

4. Helper file that gets auto-loaded

Create this file in the game folder:

File path
game/console_taboo_unlock.rpy

Paste this into that file:

console_taboo_unlock.rpy
# Ren'Py console + Taboo Mode helper
# Place this file in the game/ folder, next to the game's .rpa files.
# Restart the game fully after adding or changing this file.

# Auto-loaded at startup:
# Creates/enables the persistent special-content flag if it does not already exist.
default persistent.is_special = True

# Auto-loaded at startup:
# Enables the developer console.
init -999 python:
    config.developer = True
    config.console = True

# Auto-loaded at startup:
# Enables the game/patch flag that exposes Settings > Gameplay > Taboo Mode.
# The late init priority helps if the base game defines the flag earlier.
init 999 python:
    is_taboo_edition = True

# Optional safety placeholder.
# Keep this only if the game expects a dev_controls screen.
screen dev_controls():
    null

What the important file lines do

LinePurpose
default persistent.is_special = TrueCreates the persistent special-content preference if it does not already exist.
config.developer = TrueEnables Ren'Py developer features.
config.console = TrueAllows the console to open in-game.
is_taboo_edition = TrueExposes the Settings > Gameplay > Taboo Mode switch in this patch/game setup.

5. Console window commands

Open the console with Shift + O. Paste or type console examples there.

Console examples are marked green. They are not meant to be placed in the helper file.

set energy to max · Console window

6. How to find variables

  1. Open the game's developer tools or variable viewer, if available.
  2. Find the exact variable name shown on the left side of the equals sign.
  3. Check which viewer it appears in.
Where you saw itHow to edit itExample
Persistent ViewerPrefix the name with persistent. and save persistent data.is_special becomes persistent.is_special.
Variable ViewerUse the variable name directly.SMPlayer_Money stays SMPlayer_Money.
Use exact capitalization. True and False must start with capital letters.

8. Correct folder and file strategy

Correct

Folder layout
game/
  code.rpa
  images.rpa
  console_taboo_unlock.rpy

Wrong

Do not place here
game/saves/console_taboo_unlock.rpy
game/cache/console_taboo_unlock.rpy

The filename can be different, but it must end with .rpy and be in the game script folder.

.rpyc files are compiled/generated files. You normally edit the .rpy source file, not the .rpyc file.

10. Troubleshooting

ProblemLikely causeFix
Console does not openHelper file is missing, in the wrong folder, or the game was not restarted.Place the file in the game folder and restart fully.
Taboo Mode does not appearis_taboo_edition was not loaded or was overwritten.Use the provided helper file with init 999 python.
Variable change does not stickPersistent values were not saved, or the game overwrote the value later.For persistent values, run renpy.save_persistent(); then save/reload or restart.
Syntax error on startupIndentation or quote mismatch in the helper file.Re-copy the helper file content exactly.
